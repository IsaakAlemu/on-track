# Scope

**Goal:** One thing I want to finish, with a name, like "Finish the Python course".

**Unit:** The smallest piece of a goal that is either done or not done, like a chapter or a feature. All the units added together make the goal.

**Deadline:** The date I want the goal finished by. It is optional. The app compares it with the projected finish date.

**On track / late:** If the projected finish date is later than the deadline, the goal is late. If it is earlier or equal, it is on track. With no deadline, the app shows only pace and projected finish.
